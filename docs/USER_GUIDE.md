# 導入・操作ガイド

Caption Translator for YouTube の導入と操作を説明します。以下のボタン名は日本語表示の場合です。

**英語と日本語の相互翻訳にはSarashinaを使います。** 他の言語を翻訳するときは、対応するOpenAI互換APIを設定してください。
初期設定は「Sarashina・英語 → 日本語」です。拡張を使うためのプログラミングやコマンド入力は不要です。

> **APIキーは暗号化せずに保存されます。** Sarashina・OpenAI互換APIともに、保存先はこのChromeプロファイルの拡張専用ローカルストレージです。端末やそのバックアップを他人と共有する際は注意してください。詳しくは [APIキーの保存と注意点](PRIVACY.md#apiキーの保存と注意点) を参照してください。

## インストール

1. [GitHubのReleases](https://github.com/sugiyma111-byte/youtube-subtitle-translator/releases) を開き、Assetsにある `youtube-subtitle-translator-0.2.1-chrome.zip`（または新しいバージョンのChrome用ZIP）をダウンロードして展開します。「Source code」のZIPは選びません。
2. Chromeのアドレス欄に `chrome://extensions` を入力します。
3. 右上の「デベロッパーモード」をONにします。
4. 「パッケージ化されていない拡張機能を読み込む」を押します。
5. 展開した中から `manifest.json` が見えるフォルダーを選びます。
6. 拡張機能メニューから「Caption Translator for YouTube」を固定すると便利です。

開発フォルダーから試す場合は、ビルド後の `.output/chrome-mv3` を読み込めます。
保存先を決めてから読み込んでください。このフォルダーを移動・削除すると使えなくなります。

## Sarashinaを設定する

### 1. 自分のAPIキーを取得する

1. [Sarashina APIコンソール](https://chat.sarashina.ai/dashboard/api-keys) を開き、自分のアカウントでログインします。初めての場合は、サービスの案内に沿って利用を開始します。
2. 「API Keys」で新しいAPIキーを作成します。
3. 表示されたキーをコピーします。ログイン用パスワードではなく、このAPIキーを拡張に登録します。

取得手順は [Sarashina公式の「はじめに」](https://docs.sarashina.ai/introduction) に沿っています（2026年11月17日確認）。公式サンプルにある環境変数の設定やコマンド実行は、この拡張では不要です。
サービスの提供条件・料金は [Sarashina公式サイト](https://sarashina.ai/)、送信上限は [公式のレート制限](https://docs.sarashina.ai/rate-limits) で最新の案内を確認してください。

### 2. 拡張にAPIキーと翻訳方向を登録する

1. Chromeの拡張機能メニューから「Caption Translator for YouTube」を開きます。
2. 「APIキーを登録」を押します。キーが登録済みの場合は「設定を開く」または設定の要約にある「変更」から開けます。
3. 次のように設定します。

| 設定画面の項目 | 英語 → 日本語の場合 |
|---|---|
| 翻訳サービスとAPIキー | 「Sarashina」のカードを選ぶ |
| APIキー | 取得したキーだけを貼り付ける。先頭に `Bearer` や引用符は付けない |
| 原文の言語（動画の字幕） | 英語 |
| 翻訳先の言語 | 日本語 |
| 日本語の文体 | まずは「おまかせ」で利用可能 |

接続先URLとモデル名は入力不要です。拡張が翻訳専用のTranslate APIを使います。このAPIは日英・英日翻訳に対応し、モデル指定は不要です。[公式のTranslate API仕様](https://docs.sarashina.ai/api-reference/translate)
日本語 → 英語にしたい場合は、言語欄の間にある入れ替えボタンで原文を「日本語」、翻訳先を「英語」にします。

### 3. 接続を確認する

1. 「保存して接続を確認」を押します。設定を保存した後、短い例文を1回送信します。
2. キー欄の下に「接続できました。」とテストの訳文が表示されたら準備完了です。
3. 英語字幕のあるYouTube動画を開き、次の「動画を翻訳する」に進みます。

保存するとキーは入力欄から消え、「登録済み（暗号化なし）」と表示されます。変更するときだけ入力し直します。
入力欄が空になってもキーは端末に保存されています。伏字表示も保存時の暗号化を意味しません。
キーをGitHubのIssue・チャット・スクリーンショットに貼り付ける必要はありません。

## 動画を翻訳する

英語字幕があるYouTube動画で、動画内にマウスを動かし、右上の「翻訳」スイッチをオンにします。
字幕の取得・先読みが終わると、訳文が表示されます。停止するときは同じスイッチをオフにします。
停止するとYouTube本来の字幕表示も元に戻ります。

- 拡張アイコンを押して開くポップアップでも、「翻訳を開始」「翻訳を停止」で操作できます。現在のサービス・言語の要約にある「変更」から設定を開けます。
- 動画上のスイッチと丸い設定ボタンは、YouTubeの操作バーと一緒に隠れます。マウスを動かすと再び出ます。準備中・送信待ち・エラー時と、キーボードでフォーカスしている間は隠れません。
- 小さいプレーヤーでは「翻訳」の文字が省かれ、オン/オフとスイッチが残ります。
- 最初や早送り直後は「翻訳中…」が出る場合があります。数秒一時停止すると準備が進みます。
- 巻き戻した箇所の訳文は再利用されます。
- 別の動画に移動すると停止します。必要な動画で開始し直してください。
- 設定を保存すると、翻訳中の動画は新しい設定で取得し直します。
- 「字幕を再取得」は、字幕取得やAPI設定の問題を直した後に使います。

## 設定と表示言語を変える

動画の丸い設定ボタン、またはポップアップの「設定を開く」から設定ページを開きます。

- 「翻訳する言語と文体」で原文・翻訳先・日本語の文体を選びます。
- 「字幕の見え方」で「訳文＋原文」または「訳文のみ」、動画の上下の表示位置を選びます。文字サイズと先読みする長さはスライダーや［−］［+］で調整できます。
- 変更後は画面下部の「変更を保存」を押します。未保存の表示や保存・削除の結果も下部のバーに出ます。

設定ページの「表示言語 / Language」では「自動」「日本語」「English」を選べます。「自動」はChromeの表示言語に従い、日本語以外では英語になります。押すとすぐに保存・反映され、「変更を保存」は不要です。開いているポップアップや動画上の表示にも反映され、翻訳は続きます。
ポップアップ下部の「English」または「日本語」でも、そのボタンに書かれた言語へ切り替えられます。

表示言語は字幕の原文・翻訳先の言語とは別の設定です。文字サイズはプレーヤーの大きさに比例して変わりません。小さいプレーヤーで収まらない字幕は末尾を省略し、広げると元に戻します。高さが足りない場合は訳文を優先します。

## 他の言語をOpenAI互換APIで翻訳する

韓国語 → 日本語など、日英・英日以外の組み合わせではOpenAI互換APIを使います。対応言語・料金・利用上限は接続するサービスとモデルによって異なります。
「OpenAI互換」はAPIの形式を指します。そのサービスが発行したAPIキーを使ってください。Sarashinaのキーを他社の接続先に入力する必要はありません。

1. 利用するサービスで、Chat Completions APIに対応したベースURL・モデル名・APIキーを確認します。
2. 設定の「翻訳サービスとAPIキー」で「OpenAI互換API」のカードを選びます。
3. 「接続先のベースURL」「モデル名」「APIキー」を入力します。「1分あたりの送信上限」は利用サービスの上限に合わせます。
4. 原文と翻訳先の言語を選びます。例えば韓国語 → 日本語なら、原文を「韓国語」、翻訳先を「日本語」にします。一覧にない言語は「その他（言語コードを指定）」で設定します。
5. 「保存して接続を確認」を押し、Chromeから求められた接続先へのアクセスを許可します。短い例文の送信もサービスの利用量に含まれます。
6. 接続確認が成功したら、原文言語の字幕があるYouTube動画で翻訳を開始します。

ベースURLが `https://example.com/v1` なら、送信先は `https://example.com/v1/chat/completions` になります。これは入力形式の例で、実際の翻訳サービスではありません。
ベースURLに `/chat/completions` まで入れると二重になるため、サービスが指定するベース部分を入力してください。

ベースURLを変更すると、別サービスへの誤送信を防ぐため以前の互換APIキーを削除します。
新しい接続先のキーを登録してください。サービスは手動で切り替える方式で、Sarashinaからの自動切り替えは行いません。

> 互換APIのキーも、Chromeプロファイル内の `chrome.storage.local` に**暗号化せず保存**します。信頼できる接続先だけを指定し、有料サービスでは利用状況や予算・利用上限も確認してください。保存ファイルが流出した場合、キーを使われる可能性があります。

## この端末に保存したデータを削除する

設定ページの「この端末に保存したデータ」に、保存した訳文と両サービスのキーがまとまっています。

- APIキーは、対象サービスの行で「削除」を押し、確認ダイアログの「削除する」で確定します。両サービスのキーを消す場合は、各行で操作します。
- 選択中のサービスのキーは、APIキー欄の「このキーを削除」からも、確認して削除できます。
- 訳文キャッシュは「保存した訳文を削除」を押し、確認ダイアログの「削除する」で確定します。

削除には「変更を保存」は不要です。削除の結果は下部のバーに表示されます。
端末からの削除は、サービス側のAPIキーの失効とは別です。流出が疑われる場合は、発行元の管理画面でキーを無効化・再発行してください。

## うまく動かない場合

| 表示・症状 | 対処 |
|---|---|
| 翻訳スイッチが見えない | まず動画内でマウスを動かします。出ない場合は通常動画のページか確認し、再読み込みします。 |
| APIキーを登録するよう表示される | 設定でキーを登録し、接続確認を実行します。 |
| APIキー・利用権限のエラーが出る | 選択中のサービスのキーか確認し、余分な文字や `Bearer` を付けずに登録し直します。無効なキーは発行元で作り直します。Sarashinaでは接続元の制限などでも拒否されるため、キーが正しい場合は [公式のエラー説明](https://docs.sarashina.ai/introduction) を確認します。 |
| 接続確認で利用上限に達した | 表示された待ち時間の後に再試行します。動画翻訳と接続確認のどちらもAPIを利用します。 |
| 字幕本文を取得できない | YouTubeで「文字起こしを表示」を開き、原文言語を確認して「字幕を再取得」を押します。形式によっては取得できません。 |
| 指定言語の字幕がない | YouTube側の字幕言語と拡張の原文言語を合わせます。 |
| 送信間隔を調整している | 自動で続行します。他のタブの翻訳を停止すると待ち時間を抑えられます。 |
| 字幕が遅れる | 一時停止して先読みを待つか、先読み時間を長くします。長くすると利用量が増えます。 |
| 更新後につながらない | 拡張を更新し、動画ページも再読み込みします。 |
| 訳文を再生成したい | 設定の「この端末に保存したデータ」で訳文を削除し、動画の翻訳スイッチをオフにしてからオンにします。 |

## 更新

新しいZIPを展開して読み込み直します。同じフォルダーの中身を更新した場合は、拡張機能管理画面の更新ボタンを押します。
Chromeが別の拡張として認識した場合は、APIキーを再登録してください。
