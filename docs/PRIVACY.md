# データの保存と送信

## 送信するもの

翻訳を開始した動画の字幕の原文、原文と翻訳先の言語、選択した文体を、設定した翻訳サービスに送信します。
APIキーは認証ヘッダーとしてその翻訳サービスにだけ送信します。
動画の音声・映像は翻訳サービスに送信しません。独自のアクセス解析や広告はありません。

字幕取得では、開いている動画のYouTubeページと、そのページが利用する字幕・文字起こしの取得先にアクセスします。
YouTubeへのリクエストには通常のブラウザーセッションが使用されます。YouTubeのCookieを翻訳サービスに渡すことはありません。

## この端末に保存するもの

- 設定、サービスごとのAPIキー：Chromeの拡張専用ローカルストレージ（`chrome.storage.local`）
- 翻訳結果：拡張専用IndexedDB。最大2,000件・30日を目安に古い結果を整理
- 送信時刻・待機期限：拡張用の一時ストレージ（`chrome.storage.session`）

## APIキーの保存と注意点

**当面は、APIキーを保存時に暗号化しない設計です。Sarashina・OpenAI互換APIの両方に適用されます。**
解除用パスワードの設定や、起動時のロック解除機能はありません。Sarashina等のサービスへのログイン用パスワードを拡張に入力・保存することもありません。

| 項目 | 現在の扱い |
|---|---|
| 保存場所 | 利用中のChromeプロファイルにある、拡張専用の `chrome.storage.local` |
| 保存形式 | APIキーの文字列を暗号化せず保存。入力欄の伏字や保存後の空欄表示は暗号化を意味しない |
| 再起動後 | キーは残り、再入力せず利用可能 |
| サービスごとの保存 | Sarashina用とOpenAI互換API用を分けて保存。互換APIの接続先変更時は以前の互換APIキーを削除 |
| Chrome同期・GitHub | キーをChromeの同期ストレージやGitHubへ送信する処理はない。プロジェクトのファイルにも書き込まない |
| API送信時 | 選択した翻訳サービスへ、HTTPSの認証ヘッダーで送信 |

キーと設定のストレージは拡張の信頼された画面・バックグラウンドだけからアクセスできるよう制限しています。
YouTube上の表示処理にはAPIキーを渡しません。ただし、このアクセス制限や通信時のHTTPSは、端末上の保存データを暗号化する仕組みではありません。

端末の保存ファイル、Chromeプロファイルのコピー、バックアップなどを第三者が読める場合、APIキーを読み取られて不正利用される可能性があります。
特に有料のOpenAI互換APIでは、不正利用による料金発生にも注意が必要です。自分で管理するChromeプロファイルを使い、キーをIssue・チャット・公開ファイルへ貼り付けないでください。
利用サービスに予算や利用上限の設定があれば併用し、共有・管理外の端末にはキーを保存しないようにしてください。

Sarashinaの [公式のAPIキー管理ガイド](https://docs.sarashina.ai/introduction) は、保護されたバックエンド等からの利用を案内しています。本拡張は、利用者自身のキーでChromeから直接APIへ接続する構成です。サーバー側の保管庫と同等の保護は提供しません。

## 削除とキャッシュ

設定画面で対象サービスを選び、「登録したキーを削除」を押すと、そのサービスのキーを端末から削除します。両方のサービスのキーを消す場合は、それぞれで操作してください。
端末から削除しても発行元のキーは失効しません。流出が疑われる場合は、発行元の管理画面で無効化・再発行してください。

訳文キャッシュも暗号化していません。キャッシュを探すための識別子は原文と設定のハッシュで、原文そのものは保存しませんが、訳文は文字列で保存されます。
「保存した訳文を削除」でキャッシュを削除できます。拡張をアンインストールすると拡張の保存データも削除されます。既に作成されたバックアップは別途管理してください。
既に翻訳サービスへ送信したデータの取扱いは、そのサービスの規約・プライバシーポリシーに従います。

## 権限

| 権限 | 用途 |
|---|---|
| storage | 設定、APIキー、送信制限の状態を保存 |
| www.youtube.com | 視聴中動画の字幕取得・字幕の表示 |
| api.sarashina.ai | Sarashinaへの翻訳依頼 |
| 任意のHTTPSホスト（任意権限） | カスタムAPI設定を保存するとき、指定した接続先だけ許可を求める |

ページの内容は信頼しません。字幕はHTMLとして解釈せず文字列で表示し、外部ページからAPIキーの取得や設定変更を行える窓口は設けません。
